# TLabs Agent Framework -- Charter Pointer

Full rules live in `AGENTS.md` at the project root -- read it in full
before starting work. The files in this `.roo/rules/` directory are a
condensed, natively-loaded copy of that charter for Zoo Code / Roo Code,
kept in sync by hand. If anything here conflicts with `AGENTS.md`,
`AGENTS.md` is correct -- flag the mismatch so it can be fixed.

Project state lives in `.ai/` (see `.ai/STATUS.md` and
`.ai/CONVENTIONS.md`), not in this file. Read `.ai/STATUS.md` at the start
of every session.

Session memory for Zoo/Roo Code lives in `memory-bank/` -- refresh
`memory-bank/activeContext.md` and `memory-bank/progress.md` from
`.ai/STATUS.md` at the start and end of every session.
